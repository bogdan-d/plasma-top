# Issue 13 disk-I/O discovery evidence

Captured on the development host from base `1fbb91d040a8c6e1512353f1ef18f8e9e7e520d8`. Before changing semantics, a bounded ignored test called the existing typed resolver once and recorded `Err kind=NotFound message=block device is unavailable in sysfs`. The temporary diagnostic test was then removed. `before/typed-diagnostic.*` preserves its exact command/output, while `before/host-topology.txt` records the matching root topology: `/proc/mounts` reports `composefs / overlay`, and `/sys/class/block/composefs` does not exist.

The failure was therefore a stable unsupported pseudo-filesystem source, not an unreadable procfs or sysfs boundary. The resolver had parsed `composefs` as a block-device label and required a corresponding sysfs node. It now returns confirmed absence for a non-path source such as `composefs`, so DiskIo inventory remains at its normal 60-second cadence. Absolute device paths still resolve by canonical target or basename; ordinary whole disks, partitions, mapper names, and alternate absolute symlinks retain support.

Deterministic tests preserve the boundary distinction: missing/unreadable/malformed mount enumeration, a mount table without the requested root, and missing/incomplete sysfs for an absolute device source remain typed errors that retain inventory and enter bounded retry. Other tests cover confirmed absence, later identity appearance, source change/removal, cancellation/invalidation, and stale completion rejection. Broad multi-parent layered-device resolution remains unsupported rather than guessed.

Three normal and three CPU-0 4.2-second release `main` runs each reported exactly one `Inventory(DiskIo)` attempt with `captured=1`, `failed=0`, and no DiskIo sampling identity on this host. The former six-attempt failure burst is gone. Worst final first paint was 105.326 ms, scheduled publication p99 2.382 ms, and shutdown 6.242 ms. Every run reported zero skipped display deadlines, zero first paints over 250 ms, zero publications over 50 ms, and `final_status: ok`.

Independent verification passed focused disk, discovery, catalog, scheduler timing/identity, and async-loop tests plus all gates in `docs/DEVELOPMENT.md`: locked dependency stability, formatting, all-target/all-feature check, Clippy with warnings denied, all-target/all-feature tests, docs, repository gate, shell syntax, user-install test, package-layout test, `git diff --check`, and touched handwritten line limits. Qt verification was not applicable because no render, QML, CSS, or applet files changed. No Plasma workflow ran.
